## Structure

- `public/bag2-brand-assets/icons/ppt-source/`: SVG assets from the PowerPoint media folder.
- `public/bag2-brand-assets/images/ppt-source/`: PNG assets from the PowerPoint media folder.
- `public/bag2-brand-assets/manifest.json`: machine-readable inventory for future slide mapping.

## Usage Rules

- Use SVG assets as reusable icons or small visual accents beside Arabic text.
- Use PNG assets only when the slide needs the original raster image from the PowerPoint.
- Keep these source assets unchanged; create optimized/renamed derivatives in a separate folder when a slide needs a curated asset.
- Preserve transparent backgrounds and the bag identity palette.
