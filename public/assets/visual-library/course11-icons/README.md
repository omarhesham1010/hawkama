# Course 11 generated icon family

These 22 transparent WebP assets are the flat-v3 pictogram family generated for
`#/course/11`. They replace the rejected glossy 3D shield/badge family, including
the first slide's shield, medical cross, and magnifier. The replacement first
image is an inspection clipboard and magnifier, with no shield or medical cross.
All images use bold dark-green outlines, emerald, ochre, turquoise, and opaque
cream interiors for contrast on light and active dark-green slide backgrounds.

Production constraints:

- one compact flat 2D pictogram per file;
- no metallic rendering, bevels, 3D badges, shields, or medical crosses;
- no duplicated symbol inside the same icon;
- no text, letters, numbers, logos, or watermarks;
- true transparency outside the pictogram;
- strong silhouette and contrast at small slide sizes;
- no pale-only line art that can disappear during automatic background
  treatment.

The original generated PNGs remain in Codex's generated-images store. Project
assets are resized to 512×512 WebP for LMS/SCORM performance while preserving
alpha transparency. Generation used the built-in imagegen tool (not CLI/API).
The complete final prompt set is recorded in
`docs/course11-flat-icon-prompts.md`. Rejected v2 WebPs are retained only as a
recoverable backup in `docs/archives/course11-icons-glossy-v2/`, outside the
published public assets and SCORM package.
